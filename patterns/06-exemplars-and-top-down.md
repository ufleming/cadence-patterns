# 6. Exemplars and top-down descriptions

**Every element links to an exemplar of its kind, and every description reads from a one-sentence idea down to details.**

## Problem

Without an exemplar, each new element copies whichever neighbour its author happened to see, and layouts drift apart. A description that starts with details hides its idea: humans stop reading, and agents must read everything to find the purpose.

## Rule

- Keep one polished exemplar per element type; every other element links to it.
- Order of a description: the idea in a plain sentence → who passes what to whom → a diagram → deeper details → links and metadata → agent-only material, collapsed, at the end.
- Comments written by agents follow the same order.
- The split between the human part and the agent block is described in [two audiences](14-two-audiences.md).

Agents migrating an old element find the newest layout through its exemplar link.
